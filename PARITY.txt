本次对齐范围
- 共用编辑器；大屏浏览器使用左侧大预览、右侧固定编辑面板，不再沿用手机窄栏。
- 16 款原创模板适配六寸横竖、三寸方形、四寸拼接单幅。
- 拼接每张照片独立模板、无模板混排、奇数末张重复、裁切与对象坐标。
- 原模板移除后的草稿保留照片和文字；不恢复未授权素材。
- 竖屏空页与有照片共用固定照片选择区；底部五个工具无需滚动寻找。
- 深浅主题、手机与桌面视口；模板打开不改变页面宽度。
- 文字初始为空；文字和表情支持 Delete、Backspace，输入框不拦截。
- 表情直接平铺，可滚动至最后一类。
- 姓名贴间隙零值和恢复默认、月历跨年、卡片及 ID 卡贴现有回归。

保留的平台差异
- 新 Web 使用 App 编辑器，不复制旧 Web 页面布局。
- 原生 App 负责蓝牙权限及系统设置，浏览器通过服务设备打印。
- 浏览器草稿、照片与历史按配对会话隔离，不迁移旧 Web 草稿。
- 浏览器未知任务仍需服务设备核对；此轮不改任务恢复策略。
- AirPrint 使用系统打印界面，不提供自定义编辑工具。
- 原版位图模板没有逐个复刻，使用已有 16 款原创设计的多纸型版本。

验收边界
- 浏览器测试使用合成图片，未连接打印机。
- 打印尺寸和批次通过离线合成验证，出纸效果仍需实机验收。
- 不修改旧 Web 或 AirPrint 生产服务，不自动部署或 push。

大屏专项回归：1280×720、1440×900、1920×1080，深浅主题；五工具、侧栏独立滚动、模板选择、确认弹窗、缩回手机尺寸。
